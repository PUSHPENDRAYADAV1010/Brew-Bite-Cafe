## 📌 About The Project

**Brew & Bite Cafe** is a modern front-end cafe ordering website
built to provide customers with a smooth digital ordering experience.

The application allows customers to:

- Browse a cafe menu
- Search for products
- Filter products by category
- Filter products based on dietary preferences
- View individual product details
- Customize products according to available options
- Adjust quantities
- Add customized products to the cart
- Edit cart items
- Select an order type
- Place an order
- Receive an order confirmation
- View estimated preparation time

The project focuses on creating a clean interface with low cognitive
load, clear navigation, responsive layouts, and an easy ordering flow.

## 🎨 Product Customization
😃
Instead of showing the same options for every product, the application
uses **product-specific customization**.

Depending on the selected product, customers may be able to choose
different options such as:

- Size
- Milk type
- Temperature
- Sweetness
- Extra ingredients
- Toppings
- Other product-specific preferences

The price updates dynamically according to selected options where
applicable.
